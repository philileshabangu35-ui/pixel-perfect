# SHARON AI — Setup

1. Install: `bun install`
2. Run: `bun run dev` (http://localhost:8080)
3. AI key: `LOVABLE_API_KEY` is provided as a server-side secret by Lovable. It is read only in `src/lib/ai.server.ts` and never sent to the browser.
4. Deploy: use Publish in Lovable.

Pages: Dashboard, Research Assistant, Article Summarizer, Insights, Email Generator, History, Settings.
